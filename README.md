# Isometric2DGame

A 2D isometric game prototype developed in **Unity 6** for the **Runic Dice Entertainment (RDE) Programming Trial**.

Author: **Hakim FEKAIRI**

## Overview

The project showcases gameplay programming in a 2D isometric environment, focusing on player movement, enemy AI, and custom gameplay systems.

### Technologies
- **Engine:** Unity 6000.4.1f1
- **Template:** 2D Universal Render Pipeline (URP)
- **Input:** Unity New Input System
- **Version Control:** Git
### Features
- Isometric player movement.
- Enemy AI implemented using a Finite State Machine (FSM).
- Custom gameplay systems and mechanics.
